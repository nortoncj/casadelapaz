== Description ==

Casa De La Paz is a beautiful and compassionate WordPress theme designed specifically for Casa De La Paz Independent Living. This theme features a peaceful design with dedicated templates for showcasing services, about information, contact forms, galleries, and a fully functional blog.

The theme comes with:
* Beautiful homepage matching the original design
* Custom page templates for About, Services, Contact, and Gallery
* Blog archive and single post templates
* Responsive design that works on all devices
* Accessibility-ready with WCAG 2.1 compliance
* Clean, semantic HTML5 markup
* Custom color scheme with peaceful, calming colors
* Integration-ready for popular plugins like Contact Form 7
* Widget-ready footer areas
* Custom navigation menus
* Translation-ready

== Installation ==

1. Upload the theme folder to /wp-content/themes/
2. Activate the theme through the 'Appearance > Themes' menu in WordPress
3. Create pages and assign templates:
   - Create a page called "About" and assign the "About Page" template
   - Create a page called "Services" and assign the "Services Page" template
   - Create a page called "Contact" and assign the "Contact Page" template
   - Create a page called "Gallery" and assign the "Gallery Page" template
4. Set a static front page:
   - Go to Settings > Reading
   - Select "A static page" for your homepage displays
   - Choose your homepage for the front page
   - Choose a blog page for the posts page
5. Configure your navigation menu:
   - Go to Appearance > Menus
   - Create a new menu and assign it to "Primary Menu"
   - Add your pages to the menu
6. Customize your site:
   - Go to Appearance > Customize
   - Set your site logo
   - Configure contact information
   - Customize colors if needed

== Page Templates ==

This theme includes the following page templates:

1. **Front Page (Homepage)** - Automatically displays on the home page, featuring the complete original design with hero section, services, values, about the house, process, and contact sections.

2. **About Page** (page-about.php) - Dedicated template for the about page with facility information and features.

3. **Services Page** (page-services.php) - Showcases all services offered with the process section.

4. **Contact Page** (page-contact.php) - Contact information with integrated contact form support.

5. **Gallery Page** (page-gallery.php) - Photo gallery layout supporting WordPress native galleries and media library images.

== Blog Functionality ==

The theme includes full blog support with:

* **Archive Page** (archive.php) - Displays blog posts in a grid layout with pagination
* **Single Post** (single.php) - Beautiful single post layout with author bio, tags, and post navigation
* **Categories and Tags** - Full support for organizing posts

== Customization ==

You can customize the theme through:

1. **WordPress Customizer** (Appearance > Customize):
   - Site Identity (logo, title, tagline)
   - Contact Information (phone, email, office hours)
   - Colors (if you want to override defaults)
   - Menus
   - Widgets

2. **Custom CSS**:
   - All styles are in /assets/css/style.css
   - You can add custom CSS through Appearance > Customize > Additional CSS

3. **Widgets**:
   - Sidebar widget area
   - 3 footer widget areas

== Plugin Recommendations ==

For the best experience, we recommend installing these plugins:

* **Contact Form 7** - For the contact form on the Contact page
* **Yoast SEO** - For better search engine optimization
* **Akismet** - For spam protection on comments
* **Wordfence Security** - For website security
